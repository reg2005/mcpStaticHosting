# Configuration

Local `compose.yaml` reads `.env`; production `compose.prod.yaml` reads
`.env.production` through `scripts/compose-prod.sh`. Change values and run
`up -d` to recreate affected services. `restart` does not apply changed environment
values. Never paste rendered Compose configuration into issues: it includes secrets.

## Production

| Variable | Purpose |
| --- | --- |
| `MAIN_DOMAIN` | Required bare dashboard domain; also the system site suffix |
| `ACME_EMAIL` | Required account/recovery email for Let's Encrypt |
| `DNS_PROVIDER` | Lego provider code, e.g. `cloudflare` or `selectelv2` |
| `DNS_CREDENTIALS_PATH` | Host file, defaults to `./secrets/dns.env`; mounted only into edge |
| `MANAGEMENT_ALLOWED_CIDRS` | Comma/space-separated IPv4/IPv6 networks; blank permits any IP |
| `PUBLIC_IPV4` | Blank: automatic discovery; explicit value for NAT/ingress overrides |
| `PUBLIC_IPV6` | Optional reachable IPv6; when empty remove public AAAA records |
| `DNS_RESOLVERS` | Public resolvers; default `1.1.1.1,8.8.8.8` |
| `ACME_SERVER` | Let's Encrypt production directory by default; optional staging URL |
| `IMAGE_TAG` | `0.2.0`; all three images use the same release |
| `COMPOSE_PROJECT_NAME` | Namespace for volumes; keep stable during upgrades |
| `APP_SECRET` | Random 64-character secret generated by setup; back it up |
| `POSTGRES_PASSWORD` | Generated password used to derive the internal database URL |
| `SIGNUPS_ENABLED` | `false` in production; temporarily enable for trusted registrations |
| `RESEND_API_KEY`, `EMAIL_FROM` | Optional email delivery credential and verified sender |
| `MCP_RATE_LIMIT_PER_MIN` | `600`; per-token request limit |
| `FUNCTIONS_ENABLED` | `false`; enabling also requires the `functions` profile |
| `FUNCTION_TIMEOUT_MS` | `10000` |

Compose derives `AUTH_BASE_URL=https://MAIN_DOMAIN`,
`MCP_PUBLIC_URL=https://MAIN_DOMAIN/mcp`, `PUBLIC_BASE_DOMAIN=MAIN_DOMAIN`, and HTTPS
site URLs without ports. Only 80/443 are published. The edge credential path inside
the container is fixed at `/run/secrets/dns_credentials`.

## Local evaluation

`compose.yaml` intentionally runs without edge and uses `AUTH_BASE_URL`,
`MCP_PUBLIC_URL`, `PUBLIC_BASE_DOMAIN=lvh.me`, `PUBLIC_SITE_SCHEME=http`, and
`PUBLIC_SITE_PORT=3002`. `BIND_ADDRESS=127.0.0.1` and `WEB_PORT/MCP_PORT/ROUTER_PORT`
control local host ports. Automatic DNS/TLS and the subnet allowlist belong to the
production edge stack; local evaluation cannot activate custom-domain certificates.

Application services receive the database/Redis/storage paths from Compose. Ordinary
application secrets are runtime environment values; provider credentials are a
separate mounted file. Neither is baked into images. Keep `.env.production` mode 0600
and the DNS file inside the private directory described in [deployment](deployment.md).
Changing APP_SECRET breaks decryption of existing project secrets and invalidates
sessions. Editing POSTGRES_PASSWORD does not update an existing database role.
