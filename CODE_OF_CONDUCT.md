# Community code of conduct

We welcome contributors of all backgrounds and experience levels.

- Treat people respectfully and discuss ideas with specific, constructive feedback.
- Assume good intent and accept corrections without personal attacks.
- Do not harass, threaten, discriminate, publish private information or spam.
- Respect security reports and never post credentials or private user data.

These expectations apply in this repository's issues, pull requests and discussions.
Maintainers may edit or remove abusive content and temporarily or permanently limit
participation. Enforcement should be proportionate and consider context.

Report concerns privately to a repository maintainer using an available private
contact channel. If none is listed, ask for a private contact without exposing the
incident's sensitive details. Maintainers will review reports as time permits;
there is no guaranteed response-time commitment for this volunteer project.
